# Release Notes - v1.0 (MVP Launch)

**Date:** April 2026

## Shipped (Phase 0 - Phase 6 Complete)
- **Core Engine & Data Layer**: Local database via Drift, comprehensive financial timeline simulation, amortization calculations, and strategy sorting (Snowball vs. Avalanche).
- **Onboarding & AHA Moment**: Full guided onboarding flow leading to the "debt-free date" AHA moment.
- **Debt Management**: Full CRUD for debts, including edge cases and robust validation.
- **Payment Logging**: Logging payments manually with recalculation of the timeline in real-time.
- **Living Plan & Progress**: Dynamic, interactive timeline chart and monthly action views.
- **Trust Layer (Level 0)**: Fully localized, private, and local-only data state. Export to CSV and local device backup/restore (ZIP).
- **Localization (i18n)**: Fully translated interfaces (English and Vietnamese).
- **Marketing & Brand Assets**: High-quality App Icon, TestFlight Beta readiness, fully designed App Store Screenshots.

## Known Issues (Deferred from MVP)
- **Reporting**: Advanced PDF reporting has been deferred to Phase 10.
- **Cloud Sync**: Firebase cloud synchronization is pending implementation in Phase 7.
- **Premium Upgrades**: The paywall exists as a stub; in-app purchasing is not yet implemented.

## Next Phase Goals
- **Phase 7 (Cloud Sync)**: Implement Firebase Authentication and Firestore real-time sync with conflict resolution (LWW).
- **Phase 10 (Reports & Reminders)**: Build out the notification scheduling logic using `flutter_local_notifications` (Android already configured) for due dates and missed payments.
- **Phase 8 (Power Features)**: Premium features like what-if scenarios and progress dashboards.
